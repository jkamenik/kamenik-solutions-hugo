[Centaur Emacs](https://github.com/seagle0128/.emacs.d) is a batteries-included [[Emacs]] configuration aimed at a clean, fast out-of-the-box IDE feel. We **assess** it when evaluating Emacs distributions rather than building `init.el` from scratch.

## Blurb

> Centaur Emacs - A Clean and Fast Emacs Configuration

## Summary

Use Centaur when you want a polished Emacs starter with dashboard, LSP hooks, and broad language modules already wired. Skip it if you prefer a thinner base like [[Emacs Prelude]], or Vim-style keys via [[Spacemacs]].

Trade-off: speed to productivity vs owning less of the config surface. Upstream is `seagle0128/.emacs.d`. Personal forks exist; treat them as overlays, not the source of truth.

## Details

- **Canonical upstream:** https://github.com/seagle0128/.emacs.d
- **Noted fork:** https://github.com/danielcnorris/centaur-emacs
- **Requires:** GNU Emacs 28.1+ (prefer latest stable)
- **Fit:** [[Tool]] / [[IDE]] as an Emacs distribution, not a separate editor binary
- **Contrast:** [[Spacemacs]] (Evil-first), [[Emacs Prelude]] (closer to stock Emacs), [[Cursor]] (AI-first GUI)
