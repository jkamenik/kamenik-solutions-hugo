[Obsidian](https://obsidian.md/) is a local-first, markdown-based knowledge management system that stores notes as plain text files with bidirectional linking capabilities. We assess it for integration with agent-maintained vaults and its programmable nature.

## Blurb

> A powerful knowledge base that works on top of a local folder of plain text Markdown files.

## Summary

**When to use:** Choose Obsidian for building a local-first knowledge base with rich linking and extensibility through plugins, particularly when building an agent-maintained second brain.

**When to skip:** Opt for simpler tools if you need real-time collaboration or prefer a SaaS solution with minimal setup.

**Key trade-offs:**
- **Pros:** Local storage (data sovereignty), powerful linking, extensible via plugins, markdown-based, excellent graph view
- **Cons:** No built-in sync (requires third-party services), learning curve for advanced features, mobile app limitations

**Related:** [[PKM]] [[Markdown]]

## Details

| Topic | Notes |
|-------|--------|
| **Storage Format** | Plain text Markdown files in a local folder |
| **Linking** | Bidirectional wiki-links (`[[Note Name]]`) with autocomplete |
| **Extensibility** | Rich plugin ecosystem (community and official plugins) |
| **Graph View** | Visual representation of note connections |
| **Mobile** | Available on iOS and Android with some limitations |
| **Sync** | Requires Obsidian Sync (paid) or third-party solutions (iCloud, Dropbox, etc.) |
| **Templates** | Supports note templates for consistent formatting |
| **Search** | Full-text search with tag and property filtering |
