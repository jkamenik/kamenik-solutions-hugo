[Notion](https://www.notion.com/) is a collaborative, cloud-based workspace for teams and individuals to organize knowledge, projects, and processes in a flexible, visual format.

## Blurb

> A collaborative, cloud-native workspace for building and sharing knowledge, projects, and team workflows.

## Summary

**When to use:** Choose Notion for team collaboration, real-time co-editing, and integrating with other tools. Ideal for organizations needing a centralized knowledge hub with rich media support.

**When to skip:** Opt for local-first tools (Obsidian, SilverBullet) when data sovereignty and offline access are priorities.

**Key trade-offs:**

| Pros | Cons |
|------|------|
| Real-time collaboration | Cloud dependency |
| Rich media embedding | Subscription cost |
| Extensive integrations | Less control over data |

**Related:** [[PKM]] [[Obsidian]]

## Details

| Topic | Notes |
|-------|--------|
| **Collaboration** | Real-time co-editing, comments, and activity streams |
| **Media** | Embedded images, videos, and interactive elements |
| **Integrations** | Deep links to GitHub, Jira, Slack, and many other tools |
| **Offline** | Limited offline support compared to local-first tools |
| **Security** | Data stored in Notion's cloud infrastructure |
