Outliner tools organize information in a hierarchical, tree-like structure with collapse/expand functionality. We assess them for planning and structured knowledge work.

## Blurb

> An outliner is a type of computer program used to create and edit hierarchically organized text, with a tree structure that allows the user to collapse and expand sections of text.

## Summary

**When to use:** Choose an outliner when you need hierarchical organization, collapsing/expanding sections, and structured outlines for planning, writing, or knowledge management.

**When to skip:** Opt for flat note-taking (Obsidian with tags) if you prefer non-hierarchical linking, or mind-mapping tools for visual thinkers.

**Key trade-offs:**
- **Pros:** Hierarchical structure, easy navigation, collapse/expand, good for planning and outlining
- **Cons:** Less flexible than bi-directional linking tools, can become too rigid, learning curve for tree navigation
