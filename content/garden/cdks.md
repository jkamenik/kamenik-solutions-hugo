[CDKs](https://aws.amazon.com/cdk/). Cloud Development Kits ([AWS CDK](https://aws.amazon.com/cdk/) and similar) generate infrastructure from general-purpose programming languages.

## Blurb

> AWS Cloud Development Kit (CDK) is an open-source software development framework used to model and provision your cloud application resources with familiar programming languages.

## Summary

**Garden stance:** We **hold** CDKs for our estate.

**When to use:** Evaluate on a project when the capability clearly fits the requirement.

**When to skip:** When a simpler alternative already covers the need.
