[Visual Studio Code](https://code.visualstudio.com/) is Microsoft's extensible code editor and the upstream foundation for many editor products. We **hold** it as a direct daily driver because [[Cursor]] replaced it in this estate.

## Blurb

> The open source AI code editor

## Summary

Use Visual Studio Code when a team needs its extension ecosystem, Remote Development stack, or Microsoft integrations without adopting Cursor. For this estate, start new personal work in [[Cursor]] unless compatibility requires stock VS Code.

VS Code remains capable and actively developed. The hold rating reflects local replacement, not product deprecation. Its familiar interface and extensions made the transition from [[Atom]] easier and later carried into Cursor.

## Details

- **Upstream:** https://code.visualstudio.com/
- **Source:** https://github.com/microsoft/vscode
- **Core model:** Electron editor with extensions, language servers, debugging, terminals, and remote development
- **Estate status:** Former daily driver after [[Atom]]; superseded by [[Cursor]]
- **Fit:** [[Tool]] / [[IDE]] as an editor platform
- **Contrast:** [[Cursor]] adds the preferred agent workflow while retaining a familiar VS Code-derived interface
