[LazyGit](https://github.com/jesseduffield/lazygit) is a simple terminal UI for git commands and the TUI git client in the stack. We **adopt** it for git work that stays inside the terminal.

## Blurb

> A simple terminal UI for git commands.

## Summary

Use LazyGit for staging individual lines, interactive rebase, cherry-pick, bisect, worktrees, and undo. It earns a dedicated tab beside the editor and the agent, whether that lives inside [[Supacode]] or [[herdr]].

## Details

- **Upstream:** https://github.com/jesseduffield/lazygit
- **Role:** TUI git client in the terminal stack
- **Key features:** line staging, interactive rebase, cherry-pick, bisect, worktrees, reflog undo
- **Related:** [[git]], [[Supacode]], [[herdr]]
