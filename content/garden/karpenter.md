## Summary

[Karpenter](https://karpenter.sh/) is an open source Kubernetes node autoscaler that provisions just-in-time compute from pod constraints. It consolidates workloads, replaces underused nodes, and uses declarative `NodePool` resources instead of fixed node groups.
